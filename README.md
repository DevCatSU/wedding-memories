# Kyungsu & Tamás — Wedding Memories

Responsive GitHub Pages landing page using the supplied watercolor wedding-venue illustration.

## Google Drive

Open `index.html` and replace:

`YOUR_GOOGLE_DRIVE_FOLDER_LINK`

with your Google Drive wedding-photo folder share link.

Recommended Drive setting:
**General access → Anyone with the link → Viewer**

## GitHub Pages

Upload all files in this folder to a GitHub repository.

Then:
**Settings → Pages → Deploy from a branch → main → / (root)**

## Animation

The watercolor artwork is revealed from left to right with a soft brush-like sweep.
The welcome text then fades/slides in, and the page adapts to mobile screens.
